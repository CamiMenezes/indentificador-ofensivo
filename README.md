# Detecção de comentários ofensivos em português

Projeto da disciplina de Inteligência Artificial. O objetivo é classificar automaticamente comentários de redes sociais como ofensivos ou não ofensivos, comparando uma abordagem clássica (TF-IDF + Regressão Logística) com um modelo de linguagem pré-treinado em português (BERTimbau).

## Dataset

HateBR: https://zenodo.org/records/14397014

O arquivo não está neste repositório. Para rodar os notebooks, baixe-o pelo link acima.

- `results/`: métricas e gráficos gerados
